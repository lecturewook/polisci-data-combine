## 관심사별 저널

2026년 11월 20일 인구학·인구정책·이주·난민·소수자 대표성·미국 정치·동아시아·정책 효과평가의 학술지 18종을 추가했다. 관심사 필터는 기존 51종과 추가 18종에서 해당 분야를 다루는 저널을 함께 고른다. 필터를 적용하면 선택된 저널의 전체 발행 목록, 방법별 논문 수와 연도별 분모를 볼 수 있다. ‘한국 전문 저널’은 『한국정치학회보』, 『한국인구학』, Korea Observer를 묶는다. ‘동아시아 지역연구’에서는 이 세 저널에 Journal of East Asian Studies, Asian Survey, The China Quarterly를 더해 볼 수 있다. 개별 논문의 연구 대상 국가는 제목·초록에서 확인한다. 국제 학술지에 실린 한국 연구는 전체 발행 목록의 제목·저자 키워드 검색으로 찾을 수 있다. 한 저널을 여러 관심사에 연결할 수 있다. ## 수집 범위와 날짜

첫 실행은 서울 날짜에서 달력상 5년을 거슬러 올라간 날부터 실행일까지 포함한다. 첫날과 첫 실행일을 고정하고 이후에는 그 첫날부터 매번 다시 조회한다. 초록 유무·인용수·방법에 따른 수집 조건은 없다. Crossref의 저널 발행물에는 연구논문, 연구노트, 이론·방법론 논문, 리뷰, 서평, 정정 등이 함께 들어온다. 출판사가 종류를 표시하지 않으면 세부 유형을 미확인으로 둔다.

Crossref에 등록된 인쇄·온라인 ISSN을 OR로 결합해 발행일 필터와 커서를 사용한다. 마지막 짧은 페이지 또는 빈 페이지, 수신 건수와 보고 건수가 일치하는지 확인한다. 커서 값이 유지돼도 실제 결과가 바뀔 수 있으므로 페이지 내용으로 반복을 검출한다. OpenAlex는 같은 저널의 주 게재처와 발행 기간으로 독립 조회한다. 연도별 DOI 교집합과 차집합을 기록한다. DOI 전체 대조가 끝나지 않으면 OpenAlex의 발행연도 그룹 집계도 조회한다. 해당 응답이 없으면 저널 출처의 달력연도별 works_count를 조회해 비교 범위를 표시한다. 이 두 집계에는 비연구물도 들어가며, 달력연도 집계는 첫해와 마지막 해의 전체 연도를 가리킨다. 등록 시차와 두 출처의 발행일 정의가 다를 수 있다. DOI 차집합은 추가 확인 대상이다. 권호 목차와의 개별 연결 수, 전체 출판사 대조 여부, API 페이지 수신 완료 여부를 각각 표시한다. [Crossref API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) · [OpenAlex](https://developers.openalex.org/)

논문의 온라인 선출판일, 권호 발행일, 일반 발행일을 보관한다. 알려진 발행일 중 최초를 연도 집계에 사용하며 같은 연·월의 더 정밀한 값이 있으면 그 값을 쓴다. 연·월만 있는 경우 화면에 정밀도를 표시한다. API가 기간 안에 반환한 저정밀 날짜는 확인 가능한 범위가 수집 창과 겹칠 때 포함한다. 보완 자료의 연도만으로 시작 연도의 11월 19일 전후를 가를 수 없는 기록은 보류했다. 저장소의 등록일, Crossref 색인 시각, PoliHub 최초 발견일은 별도 항목이다.

정규화한 DOI, 제공자의 영구 논문 ID, 저널·제목·저자·발행연도·권호를 순서대로 대조한다. 대조한 목차의 표기 변형과 사전공개본은 [확인한 연결표](../catalog/journal-identities.json)에 기록한다. 원기록과 최초 발견일을 보존하고 정식 게재본 한 편으로 센다. Crossref 전 페이지 수집 뒤 기본 목록에 없는 보완 DOI를 개별 조회한다. 더 정밀한 발행일이 구간 밖이면 원기록을 남기고 집계에서 보류한다. 발행일이 들어오는 달에는 다시 포함한다. 발행 날짜 정밀도와 누락 필드는 보완할 수 있다. 상충하는 DOI와 모호한 서지 정보는 통합을 보류한다. 재현 자료·코드·외부 데이터는 논문의 관련 자료로 저장한다. 패키지 DOI나 저자 키워드가 아닌 출처의 주제 분류를 논문 DOI·저자 키워드에 대입하지 않는다.

- Göttingen SUB의 HOAD에서 선정 ISSN에 속하는 DOI와 Crossref 최초 발행연도(`cr_year`)를 대조했다. 하이브리드 오픈액세스 중심 자료이므로 구독 논문과 전면 공개 저널이 과소대표된다. 제목을 확인하지 못한 DOI도 유지한다. [사용한 R 데이터](https://github.com/subugoe/hoaddata/blob/b3e5e0bc0311a41603d094aa344dce5bc53e8c96/data/cc_articles.rda)
- Paper Picnic의 주간 Crossref 서지를 저널과 DOI로 연결해 제목·저자·초록 유무·방법 근거를 보완했다. 주간 게시일만 있는 DOI는 그 날짜로 기간을 판정하지 않았다. [현행 자료](https://github.com/sumtxt/picnic/tree/e8cb5b18d7853f3675537aeaadbc1314c7cbccf6) · [이전 수집 자료](https://github.com/sumtxt/picnic/tree/d14d91dcefa784926fa744808df56caf13612920)

[JPubE 권호 자료](https://github.com/kochiuyu/econ-journal-authors/tree/c54c997888859067223103b659f4ee98d059b71b/releases/articles_toc_2010_2025) · [Comparative Politics 공식 사이트](https://jcp.gc.cuny.edu/)

## 방법 분류와 분모

분류표는 각 방법의 원어·별칭과 한 단계 위의 개념을 담는다. 논문에서 관찰한 구체적 표현, 역할, 근거 위치·링크를 별도로 보관한다. 본문·재현 코드 직접 확인, 초록·공식 재현자료 설명에 적용 명시, 방법명 단서, 미확인의 네 수준을 사용한다. 자동 처리는 저자가 해당 방법을 사용했다고 직접 기술한 제한된 문장 패턴에 적용한다. 맥락이 불분명하거나 비교·부정·선행연구 패턴이 있으면 단서로 남긴다. 직접 확인은 사람이 근거를 대조해 추가한다. 다국어·간접 표현과 전문 전체를 포괄하는 자동 판독은 미확인 영역이다. [분류표](../catalog/methods.json) · [직접 대조한 논문](../catalog/reviewed-papers.json)

적용 확인은 직접 확인과 적용 명시를 포함한다. 같은 논문에 연결된 세부 방법들이 한 상위 분류에 속하면 가장 높은 근거 수준 한 건만 센다. 서로 다른 상위 분류에는 각각 한 번 기여한다. 서평·정정·철회·편집자료 등 식별된 비연구물은 발행목록에서 열람할 수 있고 방법 분모에서는 제외한다. 출처의 유형, 정정 표제, 또는 저·편자와 출판연도·쪽수나 가격이 함께 적힌 서평 서지를 사용한다. 리뷰 논문은 포함한다. 연도별 그래프에서 근거 확보율은 해당 논문 분모 중 초록 또는 명시적 적용 근거를 확보한 비율이다. 주간 자료의 초록은 근거 생성에만 사용했고 전문이나 설문 원본을 복제하지 않았다.

## 초록 확인과 색상 범례

방법별 막대에서 초록색 위 막대는 본문·재현 코드에서 직접 확인했거나 초록·공식 재현자료 설명에 사용이 명시된 논문 수다. 황토색 아래 막대는 해당 방법명이 등장하지만 논문에서 사용했는지 확인할 수 없는 논문 수다. 논문 한 편이 같은 상위 분류에서 두 조건에 걸치면 적용 확인으로 한 번 센다. 숫자 옆의 ‘확인’과 ‘단서’는 막대의 위아래 순서와 같다.

Crossref는 출판사가 기탁한 메타데이터를 제공한다. 초록 기탁은 권장 사항이며 논문 페이지에 있는 초록도 API에서 빠질 수 있다. Google Scholar는 논문을 찾은 뒤 원문 또는 저자가 쓴 초록이 있는 페이지로 이동하는 경로를 제공한다. 논문 상세 창에는 확인 출처, 원문, 정확한 표제로 검색하는 링크를 함께 제공한다. [Crossref의 저널 메타데이터 지침](https://www.crossref.org/documentation/principles-practices/journals/) · [Google Scholar 색인 안내](https://scholar.google.com/intl/en/scholar/inclusion.html)

매번 방법 집계 대상 중 초록이 비어 있는 논문을 다시 점검한다. 저널·발행연도별 공식 페이지 표본을 먼저 열어 DOI 또는 표제와 출판사의 명시적인 초록란을 확인한다. 이어서 확보한 DOI 목록을 OpenAlex, Semantic Scholar, OpenAIRE의 문서화된 묶음 조회로 대조하고 저널 게재본의 DOI와 표제가 일치하는 초록을 채택한다. Journal of Public Economics, Public Choice, Journal of Econometrics, Journal of Population Economics, American Economic Journal: Applied Economics는 RePEc에서 출판사가 제공한 ReDIF 배포본도 대조한다. DOI 또는 Elsevier의 고유 논문번호(PII)와 표제를 확인한다. 이 추가 출처의 로컬 조회에는 `rsync`가 필요하다. [RePEc 데이터 안내](https://ideas.repec.org/getdata.html) · [공식 배포 서버](https://rsync.repec.org/)

남은 논문은 공식 페이지로 돌아가 점검한다. 같은 한국 날짜에 반복 실행하면 출판사의 초록 미제공·접근 제한 응답과 DOI 조회에서 초록을 받지 못한 결과를 재사용하며 다음 날짜에는 다시 요청한다. 서버 오류와 전송 실패는 당일에도 재시도한다. Actions의 수동 실행 옵션 또는 로컬의 `--recheck-abstracts`로 당일 재조회를 선택할 수 있다. 출판사에서 자동 접근을 제한하면 해당 정책과 응답을 기록한다. 페이지의 일반 소개문, 검색 결과 발췌문과 잘린 텍스트는 초록 확보 건수에서 제외한다. Cambridge Core에서는 검색용 메타태그가 서평 문두나 도서 서지를 담는 경우가 있어, 독자가 볼 수 있는 Abstract 영역과 출판사의 초록 미제공 표기를 확인한다. 재검토로 철회한 초록 근거는 이력으로 보존한다. 저널 페이지를 직접 열람한 경우와 학술 색인에서 확인한 경우는 서로 다른 출처로 표시한다. [OpenAlex API](https://help.openalex.org/api/authentication/) · [Semantic Scholar Academic Graph](https://api.semanticscholar.org/api-docs/) · [OpenAIRE 조회 방식](https://graph.openaire.eu/docs/apis/graph-api-v4/quickstart/)

확인한 초록으로 방법론을 다시 분류한다. 색인에는 초록 확인 위치와 링크, 짧은 방법 근거를 남긴다. 초록을 개별 대조한 일부 논문에는 한국어 요약도 제공한다. 출판사가 초록 미제공을 명시한 경우에는 해당 안내를 연결한다. 권호 표지(Cover and Front/Back matter), 감사의 글과 편집자 안내는 발행 목록에 보존하고 방법 분모에서 뺀다. 공식 목차가 일반 서평으로 분류한 글은 제외하고, 여러 연구를 함께 검토하는 서평 에세이(Book Review Essay)는 리뷰로 포함한다. 유형을 확인한 항목에서는 출판사의 표기를 연결한다. 이러한 유형 재분류는 새 초록 확인 수와 별도로 기록한다. 원어 초록은 연결한 출처에서 읽을 수 있다. 전체 발행 기록의 초록 수, 방법 집계 대상의 초록 수, 초록 또는 방법 적용 근거가 있는 논문의 수는 분모가 달라 각각 표시한다.

## 월별 실행과 장애

`python -m polihub.journals`는 로컬과 Actions에서 같은 명령이다. 서울 매월 1일 09:20(UTC 00:20)에 예약되며 GitHub Actions의 수동 실행도 같은 고정 구간을 재조회한다. 버전 번호 또는 직접 검토한 논문·식별자 연결표가 기본 브랜치에 반영될 때에도 배포한다. 원한다면 저장소 변수 `CROSSREF_MAILTO`와 비밀 값 `OPENALEX_API_KEY`에 공식 API의 연락처·키를 설정할 수 있다. 제공자 인증 요구나 거절은 출처별 오류로 기록한다.

실행 잠금 안에서 기존 색인을 검증하고, 새 스냅샷을 같은 디렉터리에서 원자적으로 교체한다. 실패한 출처의 이전 자료와 직접 확인 근거는 보존된다. 종료 코드 2는 Crossref 일부 또는 전체 미완료다. 워크플로는 실행 요약·부분 결과를 보존한다. 저장소 반영은 fast-forward 푸시를 사용한다. 기본 브랜치가 거절하면 실행별 브랜치와 PR로 보낸다. GitHub가 봇 PR 발행을 막은 경우 실행 로그의 브랜치를 확인할 수 있다. 기본 브랜치 반영 후에는 실행별 Release에 버전 이름을 가진 HTML을 첨부하고 다시 내려받아 원본과 대조한다.
