## 실행환경과 기능 시험

- R 4.5.3, readr 2.2.0, haven 2.5.5에서 자료별 관측 수·변수 수를 대조하고 이름 있는 R 목록을 생성했다. 고정 패키지 목록으로 별도 경로에 R 환경을 다시 설치하고 버전을 대조했다.
- Stata 실행파일을 찾을 수 없어 배치·라이선스·do-file 실행 시험은 미실행이다. 8개 자료의 do-file과 frames 로더를 생성했다. Pew R 객체의 DTA 변환은 R에서 실행해 확인했다.
- 합성 자료를 사용한 자동시험 **9개 통과**. 시험에는 평균·OLS·연구자 작성 R 코드, 사전 지정 수치와 고의로 다르게 지정한 음성 대조, 실행 후 명세 변경 거절, DTA·SAV 라벨 및 사용자 결측, ZIP 다중 표·경로 검증, 서로 다른 조사 응답자 결합 거절, many-to-many 차단을 포함했다. 이 수치는 실제 논문 재현 실적과 별도로 집계했다.
- Chromium에서 여섯 분야·대상국·상세 필터·연구질문 검색, 선택 유지, 세 자료 비교, 원자료 다운로드 해시, 일괄 수집과 R 가져오기, 파일 등록, 연구명세 내보내기, 환경 진단, 모바일 폭을 확인했다. 별도 브라우저에서 네트워크를 끈 뒤 단독 HTML 본문을 로드해 탐색·비교·명세 파일 생성을 확인했다. 관리형 Chromium은 file:// 직접 탐색을 제한하여 이 경로의 파일 더블클릭은 시험하지 못했다.

## 추가 확인이 필요한 항목

- 자료 32개는 개별 배포판의 코드북·차수·접근조건 확인이 남아 있다. 국내 후보에는 KGSS, KIPA 조사, KOWEPS 복지인식 부가조사 등이 있다. 같은 프로젝트의 다른 차수에서 확인된 국가나 문항을 미확인 배포판으로 옮기지 않았다.
- CES 누적파일과 Manifesto API는 제작자의 지침을 확인했다. CES 누적 지침의 PDF 경로는 404였고 같은 커밋의 QMD 원문을 열람했다. Dataverse의 원자료 버전 및 Manifesto 인증 요청은 각각 배포처 접근과 정식 API 키가 필요하다. [CES 지침 원문](https://github.com/kuriwaki/cces_cumulative/blob/0fd71dbb5523a2795d57c3b2081b818acffd567c/guide/guide_cumulative_2006-2025.qmd) · [Manifesto 공식 API 클라이언트](https://github.com/ManifestoProject/manifestoR/blob/51f7a59d76134eb17e50a612fd61b1d0759261b6/R/manifesto.R)
- 원문 문항과 번역·표본·척도의 동등성, 인과 식별, 실제 논문 결과의 재현은 해당 자료·연구계획을 받아 검토한다. 일반 PDF·HWP 설문지의 자동 변수 추출, 모든 기관의 로그인 자동화, MCP 서버는 이번 구현 범위에 포함하지 않았다. Codex는 JSON과 CLI로 같은 작업을 수행한다.
